04 — Integrations

Developer workflow adapters

Site adapters are injected only after you invoke Alexandria on a page and grant that site access. They read the smallest available context and never submit a repository action automatically.

Puter Chat remains opt-in. Enabling this preference does not sign in, transmit data, or select Puter as the active provider.
